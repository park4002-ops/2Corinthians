cysjavis 개인정보처리방침

최종 수정일: 2026년 11월 4일

cysjavis는 순천서남교회가 자기 유튜브 채널에 설교 영상을 올리기 위해 쓰는 개인 업무용 프로그램입니다. 일반 이용자에게 제공하는 서비스가 아닙니다.

1. 이용하는 정보

  • 이 프로그램은 교회 담당자의 구글 계정으로 한 번 로그인하여 YouTube 업로드 권한(YouTube Data API)을 받습니다.
  • 그 권한으로 교회가 직접 만든 설교 영상을 교회 유튜브 채널에 올리고, 같은 채널의 재생목록에 넣습니다.

2. 수집·저장·공유

  • 다른 사람의 개인정보를 수집하지 않습니다.
  • 로그인 정보(토큰)는 교회 담당자의 개인 컴퓨터에만 저장되며, 외부 서버나 제3자에게 전송·공유·판매하지 않습니다.
  • 영상 제목, 설명, 재생목록 정보 외에 구글 계정의 다른 정보는 읽거나 저장하지 않습니다.

3. 보관과 삭제

담당자는 언제든지 구글 계정의 보안 설정(https://myaccount.google.com/permissions)에서 이 프로그램의 권한을 취소할 수 있고, 프로그램이 저장한 로그인 파일을 삭제할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책

이 프로그램이 Google API에서 받은 정보를 사용하고 다른 곳으로 전송하는 일은 제한 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
